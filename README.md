# 📁Simple Biodata Program
As simple Python program that displays user biodata using variables and the print() function. This project was created as part of my Python learning journey.

## ✨Features
- Displays user's name
- Displays user's gender
- Displays user's province
- Displays user's hobby
- Displays user's dream career

## 🛠️Technologies Used
- Python 3

## 📚Concepts Learned
- Variables
- Strings
- Integers
- Print() function

## 🖥️Example Output
'''text
 Name           : Sanja
 Gender         : Female
 Province       : East Java
 Hobby          : Watch drama, playing game
 Dream Career   : Data Scientist
 '''

## 🚀How to Run
1. Open the project using Google Colab, VS Code, or any Python IDE.
2. Run the python file
3. The biodata will be displayed in the terminal or output window.
